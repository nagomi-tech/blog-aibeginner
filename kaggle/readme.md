# Credit Card Fraud Detection Dataset

このディレクトリの `archive.zip`（`creditcard.csv`）は、以下のデータセットを再配布したものです。

- **データセット名**: Credit Card Fraud Detection
- **作成者**: Worldline および ブリュッセル自由大学（ULB）Machine Learning Group
- **公式ページ**: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
- **ライセンス**: Database Contents License (DbCL) v1.0
  https://opendatacommons.org/licenses/dbcl/1-0/

## 内容

2013年9月にヨーロッパのカード会員が行った取引データです。284,807件の取引のうち492件が不正利用（Class=1）としてラベル付けされています。プライバシー保護のため、特徴量 V1〜V28 は主成分分析（PCA）により匿名化されています（Time・Amount・Class は非変換）。

## 利用について

本データはDbCL v1.0のもとで、出典を明記すれば複製・再配布・商用利用を含めて自由に利用できます。本リポジトリでは、なごみテクノロジーのブログ記事で使用するサンプルデータとして再配布しています。

再利用される場合は、上記の出典（Worldline / ULB Machine Learning Group）を明記してください。
